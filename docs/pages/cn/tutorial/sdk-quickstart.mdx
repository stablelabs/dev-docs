# SDK 快速入门

您将安装 `@stablechain/sdk`，创建一个由私钥签名的客户端，在 Stable 测试网上发送 USDT0 转账，并获取一个主网桥接报价。总耗时：大约五分钟。

:::note
Stable 使用 USDT0 作为 Gas 代币。您只需要测试网 USDT0 即可进行交易。无需为单独的原生资产充值。
:::

## 前提条件

- Node.js 20 或更高版本
- 一个拥有测试网 USDT0 的测试私钥。请参阅[为您的测试网钱包充值](/cn/how-to/use-faucet)。

## 1. 安装

```bash
mkdir stable-sdk-quickstart && cd stable-sdk-quickstart
npm init -y && npm pkg set type=module
npm install @stablechain/sdk viem dotenv
```

```text
added 3 packages, audited 4 packages in 2s
```

`type=module` 允许您在下面的步骤中使用顶层 `await`；没有它，`tsx` 会拒绝脚本。

保存您的测试密钥：

```bash
echo "PRIVATE_KEY=0xYOUR_TEST_KEY" > .env
```

## 2. 创建客户端

创建 `index.ts`：

```ts
import "dotenv/config";
import { createStable, Network } from "@stablechain/sdk";
import { privateKeyToAccount } from "viem/accounts";

const account = privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`);

const stable = createStable({
  network: Network.Testnet,
  account,
});

console.log("Signer:", account.address);
```

```text
Signer: 0xYourAddress
```

`createStable` 接受三种签名模式：`account`（服务器端，如上所示）、`transport`（通过 `custom(window.ethereum)` 的浏览器钱包）或 `walletClient`（预构建的 viem `WalletClient`）。有关这三种模式，请参阅[将 SDK 与 viem 结合使用](/cn/how-to/sdk-with-viem)。

## 3. 发送 USDT0 转账

追加到 `index.ts`：

```ts
const { txHash } = await stable.transfer({
  from: account.address,
  to: "0x000000000000000000000000000000000000dEaD",
  amount: 0.001,
});

console.log("Transfer:", txHash);
```

运行它：

```bash
npx tsx index.ts
```

```text
Signer: 0xYourAddress
Transfer: 0x8f3a...2d41
```

在[测试网浏览器](https://testnet.stablescan.xyz)上打开哈希以确认。

## 4. 桥接报价

`bridge` 有两条路线：通过 LayerZero 的原生 USDT0 路径，以及用于其他所有情况的 LI.FI。下面的报价是 USDT 到 USDT0 的配对，所以它通过 LI.FI，它支持 Stable 主网但不支持任何测试网。`quoteBridge` 是一个只读调用（不需要签名、不需要 Gas、不需要资金），因此您可以使用相同的密钥预览主网桥接。追加：

```ts
import { Chain } from "@stablechain/sdk";

const stableMainnet = createStable({
  network: Network.Mainnet,
  account,
});

const bridgeQuote = await stableMainnet.quoteBridge({
  fromChain: Chain.Ethereum,
  toChain: Chain.Stable,
  fromToken: "0xdAC17F958D2ee523a2206206994597C13D831ec7", // 以太坊上的 USDT
  toToken: "0x779Ded0c9e1022225f8E0630b35a9b54bE713736", // Stable 上的 USDT0
  amount: 100,
});

console.log("Bridge quote:", bridgeQuote);
```

```text
Bridge quote: { toAmount: 99.73 }
```

将报价传递给 `stableMainnet.bridge({ ...params, quote })` 以执行。SDK 处理批准和链切换。

如果您报价的是 USDT0 到 USDT0，SDK 将会采取原生 USDT0 路径：1:1 且没有协议费用，报价将包含 LayerZero 消息的 `nativeFee` 和 `lzTokenFee`，而不是减少的 `toAmount`。该路径也适用于 Sepolia 和 Stable 测试网。设置 `route: "usdt0"` 或 `route: "lifi"` 以强制选择一个。有关权衡和每链支持，请参阅 [`BridgeRoute`](/cn/reference/sdk#bridgeroute)。

## 5. 兑换

同链兑换遵循相同的模式。`stable.quoteSwap` 在 Stable 的 [Uniswap v3 矿池](/cn/reference/dexes)上进行交易定价，并返回预期输出和预构建的交易。`stable.swap({ ...params, quote })` 执行它，内部处理 ERC-20 批准。该示例使用步骤 4 中的 `stableMainnet` 客户端在主网上报价。像 `quoteBridge` 一样，它是只读的。兑换也适用于测试网，针对测试网 Uniswap v3 部署。追加：

```ts
const swapQuote = await stableMainnet.quoteSwap({
  fromToken: "0x779Ded0c9e1022225f8E0630b35a9b54bE713736", // USDT0
  toToken: "0xB8CE59FC3717ada4C02eaDF9682A9e934F625ebb", // XAUt0
  amount: 100,
});
console.log("Receive:", swapQuote.toAmount, "at least", swapQuote.toAmountMin);
```

```text
Receive: 0.0241 at least 0.0239
```

`toAmountMin` 是在默认 0.5% 滑点限制后的输出。设置 `slippageBps` 以更改它。

:::note
当没有矿池为某个交易对提供流动性时，`quoteSwap` 和 `swap` 会抛出 `StableQuoteError`，其 `providerCode: "no_route"`。有关完整的 API，请参阅 [SDK 参考中的 `quoteSwap`](/cn/reference/sdk#quoteswapparams)。
:::
