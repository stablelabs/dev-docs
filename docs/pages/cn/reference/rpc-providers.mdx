支持 Stable 的 RPC 和开发者基础设施提供商。

## Alchemy

一个受全球信任的完整区块链开发平台。[开始使用 Alchemy](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable)

**功能**

- RPC + WebSocket 基础设施
- 监控仪表板
- 开发者 API 和 SDK

**开始使用**：在 [Alchemy 仪表板](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable)中创建 Stable 应用以获取 RPC URL，然后将其用作您的 JSON-RPC 端点。

## Chainstack

Chainstack 为 Stable 提供托管 RPC 节点。您可以通过 HTTPS 或 WebSocket 连接到已部署的节点。

**功能**

- 托管 RPC 节点
- HTTPS 和 WebSocket 端点
- 完整和归档节点访问

**开始使用**：在 [Chainstack 控制台](https://console.chainstack.com/)中创建项目，选择 Stable，然后部署节点。将其 HTTPS 或 WebSocket 端点复制到您的应用程序中。

## Goldsky Edge RPC

Goldsky Edge RPC 是用于 Stable Mainnet 和 Testnet 的托管 RPC 端点，从多个区域提供服务。它基于 [eRPC](https://github.com/erpc/erpc) 构建，这是一个开源 RPC 代理，您也可以自行运行。

**功能**

- HTTPS JSON-RPC 端点（不支持 WebSocket）
- 链数据缓存
- 使用情况、延迟和错误仪表板

**开始使用**：在 [Goldsky 仪表板](https://app.goldsky.com)中创建 API 密钥，然后向 `https://edge.goldsky.com/standard/evm/988?key=YOUR_KEY` 发送 JSON-RPC 请求。Testnet 使用链 ID `2201`。

## PublicNode

PublicNode by Allnodes 为 Stable 提供免费公共 RPC 端点，无需创建账户。

**功能**

- EVM JSON-RPC 和 WebSocket 端点，无需注册即可免费使用
- Cosmos RPC、REST 和 gRPC-Web 端点
- 在 [publicnode.com/snapshots](https://www.publicnode.com/snapshots#stable) 提供修剪和归档节点快照

**开始使用**：从 [stable.publicnode.com](https://stable.publicnode.com) 复制端点到您的应用程序，例如使用 `https://stable-evm-rpc.publicnode.com` 作为 EVM JSON-RPC 端点。

## Tenderly

一个提供模拟、调试、监控和执行工具的全栈开发平台。

**功能**

- 实时合约模拟
- 调试和追踪
- 开发者交易工作流

**开始使用**：在 [Tenderly 仪表板](https://tenderly.co/)中设置 Stable 项目，以访问用于您合约的模拟、调试和交易追踪功能。
