# RPC 제공업체

Stable을 지원하는 RPC 및 개발자 인프라 제공업체입니다.

## 개요 테이블

| **제공업체** | **카테고리** | **문서 / 시작하기** | **참고** |
| :--- | :--- | :--- | :--- |
| [**Alchemy**](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable) | RPC + 개발자 플랫폼 | [Alchemy 시작하기](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable) | RPC, WebSocket, 모니터링, SDK |
| [**Chainstack**](https://chainstack.com/) | RPC + 노드 인프라 | [Chainstack 시작하기](https://console.chainstack.com/) | 관리형 RPC, WebSocket, 전체 및 아카이브 노드 |
| [**Tenderly**](https://tenderly.co/) | 시뮬레이션 + 디버깅 | [tenderly.co](https://tenderly.co/) | 실시간 시뮬레이션, 트레이싱, 트랜잭션 워크플로우 |

## Alchemy

전 세계적으로 신뢰받는 완전한 블록체인 개발 플랫폼입니다. [Alchemy 시작하기](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable)

**기능**

- RPC + WebSocket 인프라
- 모니터링 대시보드
- 개발자 API 및 SDK

**시작하기**: [Alchemy 대시보드](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable)에서 Stable 앱을 생성하여 RPC URL을 얻은 다음, 이를 JSON-RPC 엔드포인트로 사용하십시오.

## Chainstack

Chainstack은 Stable을 위한 관리형 RPC 노드를 제공합니다. HTTPS 또는 WebSocket을 통해 배포된 노드에 연결할 수 있습니다.

**기능**

- 관리형 RPC 노드
- HTTPS 및 WebSocket 엔드포인트
- 전체 및 아카이브 노드 액세스

**시작하기**: [Chainstack 콘솔](https://console.chainstack.com/)에서 프로젝트를 생성하고, Stable을 선택한 다음, 노드를 배포하십시오. 해당 HTTPS 또는 WebSocket 엔드포인트를 애플리케이션에 복사하십시오.

## Tenderly

시뮬레이션, 디버깅, 모니터링 및 실행 도구를 제공하는 풀스택 개발자 플랫폼입니다.

**기능**

- 실시간 계약 시뮬레이션
- 디버깅 및 트레이싱
- 개발자를 위한 트랜잭션 워크플로우

**시작하기**: [Tenderly 대시보드](https://tenderly.co/)에서 Stable 프로젝트를 설정하여 계약에 대한 시뮬레이션, 디버깅 및 트랜잭션 트레이싱에 액세스하십시오.
