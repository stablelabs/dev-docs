## 类别指南

- **用户钱包：** 这些是传统的面向消费者的钱包，例如移动应用程序、浏览器扩展或交易所关联钱包。它们允许用户持有 USDT、进行转账、连接到 dApp 并直接与 Stable 交互。
- **钱包 SDK：** 一种软件开发工具包，为开发人员提供预构建的工具、API 和基础设施，以便将钱包创建、密钥管理、交易签名和区块链交互直接集成到他们的应用程序中。
- **托管 / 机构钱包：** 为机构提供受监管的企业级资产托管的平台。这些解决方案侧重于合规性、治理控制、安全密钥管理和资金运作，而不是终端用户流程。
- **嵌入式 / 应用内钱包：** 通过 SDK 或后端系统在应用程序内部生成的钱包。这些功能可实现主流用户的无缝入职，而无需他们安装或理解外部加密钱包。
- **智能钱包 / 账户抽象：** 支持自定义逻辑的可编程钱包，例如无 Gas 交易、捆绑操作或自动化执行。这些通过开发人员定义的行为扩展了基本钱包功能。
- **MPC 钱包提供商：** 使用多方计算 (MPC) 将私钥控制分发到多个方或设备的密钥管理系统。非常适合需要高安全性托管而无需传统助记词的应用程序或企业。
- **连接提供商：** WalletConnect (Reown) 等协议，用于连接钱包和 dApp。它们不存储资产，也不充当钱包本身；相反，它们为交易签名和交互提供安全的通信渠道。

## 1. 用户钱包

这些是全球主要交易所提供的终端用户钱包。它们允许用户持有 USDT、转移资金并连接到 Stable 上的应用程序。

### Stable Pay

一个基于 Stable 构建的非托管支付钱包，专为快速、稳定币原生交易而设计。Stable Pay 提供即时 USDT 支付、可预测的费用和针对日常转账和商业优化的简单用户体验。

**功能**

- Stable 的非托管钱包
- 即时 USDT 支付
- 可预测且一致的交易成本
- 直接构建在 Stable 的 USDT 原生结算层上
- 消费友好的 UI，专为支付和商业设计

### 币安钱包

一个广泛使用的多链钱包，与全球交易量最大的交易所集成。

**功能**

- 支持 Stable USDT
- 与币安生态系统直接集成
- 移动和扩展钱包选项

### Bitget 钱包

连接到 Bitget 交易所生态系统的多资产钱包，支持加密货币、股票和 ETF。

**功能**

- 支持 Stable USDT
- 内置 dApp 浏览器
- 与 Bitget 交易账户无缝集成

### Gate 钱包 (Gate Onchain)

一个由全球最大的现货交易所之一支持的钱包产品。

**功能**

- 支持 Stable USDT
- Gate 交易所和钱包之间轻松转账
- dApp 和 Web 应用程序连接

### OKX 钱包 (OKX Onchain)

一个功能强大的全球多链钱包。

**功能**

- 支持 Stable USDT
- 深度 OKX 生态系统集成
- Web、移动和扩展钱包选项

### Atomic Wallet

一个非托管多资产钱包，可在桌面、移动和作为浏览器扩展程序使用。Atomic Wallet 集成了 [Simplex by Nuvei](/cn/reference/ramps#simplex-by-nuvei) 入口，因此用户可以使用卡、Apple Pay、Google Pay 或银行转账在应用程序内直接在 Stable 上购买 USDT。

**功能**

- 在 Stable 上持有、发送和接收 USDT
- 私钥本地存储在用户设备上
- 通过 Simplex 在应用程序内购买 Stable USDT
- 适用于 Windows、macOS、Linux、iOS、Android 和 Chrome

**开始使用**：从 [atomicwallet.io](https://atomicwallet.io/downloads) 下载 Atomic Wallet，添加 Stable 作为网络，然后使用应用程序内的购买流程通过 Simplex 购买 Stable USDT。

## 2. 钱包 SDK

### Tether 钱包开发套件 (WDK)

Tether 的开源 SDK，用于在任何平台和区块链上构建自托管钱包。

**功能**

- 多链支持：比特币、以太坊、TON、TRON、Solana、Spark 等
- 代理钱包：原生支持 Stable 上的 AI 代理钱包和 x402 支付
- DeFi 集成：支持插件互换、桥接和借贷协议
- 可扩展设计：为新的区块链或协议添加自定义模块

**开始使用**：安装 [`@tetherto/wdk`](https://www.npmjs.com/package/@tetherto/wdk) 和 [`@tetherto/wdk-wallet-evm`](https://www.npmjs.com/package/@tetherto/wdk-wallet-evm)，然后按照 [WDK 文档](https://docs.wallet.tether.io) 将 Stable 配置为目标链。

## 4. 嵌入式 / 应用内钱包

通过 SDK 直接嵌入到应用程序中的钱包，实现无缝的用户入职和支付流程。

### Coinbase 开发者平台 (CDP)

CDP 为面向用户的应用程序和后端系统提供非托管钱包。用户身份验证钱包使用电子邮件、短信或社交登录。API 密钥钱包允许服务器管理账户，而 CDP 则在受信任的执行环境中保护私钥。

**功能**

- 无助记词的嵌入式钱包
- 用于自动化工作流和后端服务的 API 密钥钱包
- EVM 账户创建和交易签名
- 用户控制钱包的密钥导出

**Stable 集成**

Coinbase 钱包 API 支持 Stable，因为它支持所有 EVM 兼容网络。使用链 ID `988` 和 `https://rpc.stable.xyz` 配置 Stable，或者使用 CDP 签名并通过 Stable 的 RPC 广播。

Coinbase Onramp 是一个独立的法币兑加密货币产品，不支持 Stable。

**开始使用**：遵循 [CDP 非托管钱包文档](https://docs.cdp.coinbase.com/wallets/non-custodial-wallets/overview)，并选择用户身份验证或 API 密钥快速入门。

### Dynamic

企业级钱包基础设施，服务于数千个应用程序和超过 4000 万用户。

**功能**

- 钱包创建和认证
- 嵌入式钱包流程
- 应用程序和金融科技的用户入职

**开始使用**：遵循 [Dynamic SDK 设置文档](https://docs.dynamic.xyz/introduction/welcome) 安装 SDK 并在您的应用程序中将 Stable 配置为支持的网络。

### Privy

Privy 为用户、组织、财务和代理提供嵌入式钱包。钱包可以使用非托管或托管配置。

**功能**

- 使用电子邮件、社交登录、Passkey 或外部钱包进行身份验证
- 嵌入式 EVM 钱包创建和交易签名
- 签名者、接收者、合约和转账金额的策略控制
- 用户控制的非托管钱包密钥导出

**开始使用**：遵循 [Privy 嵌入式钱包文档](https://docs.privy.io/wallets/overview/embedded) 创建钱包，然后在您的应用程序中将 Stable 配置为 EVM 网络。

### Portal

Portal 通过适用于 Web、iOS、Android 和 React Native 的 SDK 以及用于服务器端集成的 API 提供 MPC 钱包。MPC，即多方计算，将签名权限分散到独立的密钥份额中。

**功能**

- 嵌入式 EVM 钱包创建、备份和恢复
- 消息和交易签名
- EVM 网络的自定义 RPC 配置
- Web、移动和 API 集成选项

**开始使用**：遵循 [Portal SDK 快速入门](https://docs.portalhq.io/sdks/quickstart)，然后将 Stable 的 CAIP-2 链 ID (`eip155:988`) 映射到 `rpcConfig` 中的 `https://rpc.stable.xyz`。

### Turnkey

Turnkey 提供嵌入式钱包，并在受信任的执行环境 (TEE) 中进行签名和策略评估。TEE 是一种隔离的硬件支持环境，可在签名期间保护密钥。

**功能**

- 使用电子邮件、电话、社交登录、Passkey 或生物识别技术进行身份验证
- 跨 EVM 兼容网络的嵌入式钱包
- 非托管、托管和混合托管模型
- 可编程签名策略和按用户隔离

**开始使用**：遵循 [Turnkey 嵌入式钱包概述](https://docs.turnkey.com/solutions/embedded-wallets/overview)，选择一个 SDK，并将 Stable 配置为 EVM 网络。

### Reown (原 WalletConnect)

一个广泛采用的用于连接钱包到应用程序的标准。

**功能**

- 安全的钱包到 dApp 连接
- 支持移动、桌面和扩展钱包
- 广泛的生态系统兼容性

**Reown SDK 用于钱包入职**

Stable 支持与 **Reown SDK** 集成，帮助开发人员为用户提供无缝的钱包和入职体验。

Reown 提供一个开源、一体化的 SDK，作为 WalletConnect 网络的官方网关。它可以在您的应用程序中实现流畅的钱包连接、交易、登录、嵌入式钱包（电子邮件和社交登录）、链上支付、应用内互换等。

**开始使用**

- 访问 Reown 的文档：[https://docs.reown.com/overview](https://docs.reown.com/overview)

### Safe

Safe 是一个智能合约账户，只有在其所有者中的设定数量批准后才会执行交易。这称为 m-of-n 多重签名：n 个所有者中的任意 m 个必须签名。所有者可以是 EOA、硬件钱包或其他 Safe 账户，模块和守卫添加了可编程逻辑，例如支出限制或恢复。

**功能**

- 具有可配置签名阈值的多重签名智能账户
- 批量交易，因此多个调用在一个交易中原子结算
- 用于支出策略、恢复和自动化的模块和守卫
- 无需将资产移动到新地址即可更改所有者和阈值
- ERC-1271 合约签名和链下签名收集
- Passkey 所有者，因此 Safe 可以通过设备生物识别或安全密钥而不是助记词签名
- 通过 Safe4337Module 实现 ERC-4337 执行，用于捆绑用户操作和赞助 Gas
- Safe\{Core\} SDK 工具包，用于账户部署、交易提案和索引

**Stable 集成**

Safe 在 Safe\{Wallet\}、Safe\{Core\} SDK 和 Safe Transaction Service 中支持 Stable 作为网络。链前缀是 `stable`，因此 Safe 地址写为 `stable:0x…` 并在 `https://app.safe.global` 打开。Stable 的 Transaction Service 运行在 `https://api.safe.global/tx-service/stable`，这是您传递链 ID `988` 时 API Kit 使用的。

规范合约以其确定性地址部署，版本为 1.3.0、1.4.1 和 1.5.0，因此硬编码 Safe 地址的工具可以在 Stable 上运行而无需自定义部署。1.4.1 地址为：

| Safe（单例）       | `0x41675C099F32341bf84BFc5382aF534df5C7461a` |

在第一次交易之前为 Safe 注入 USDT0，因为 USDT0 是 Stable 上的 Gas 资产。

**Passkey**

Passkey 所有者是 WebAuthn 凭证，例如设备生物识别或安全密钥，代表 Safe 进行签名。`SafeWebAuthnSignerFactory` 为凭证的公钥部署一个 signer 合约，然后该合约作为 Safe 所有者添加。如果您想要一个没有为每个凭证部署合约的 Passkey 所有者，`SafeWebAuthnSharedSigner` 是替代方案。两者都部署在 Stable 上，以及 signer 配置指向用于签名检查的 Daimo P-256 验证器。

**ERC-4337**

`Safe4337Module` 部署在 Stable 上，并在 Safe 上作为模块和 fallback handler 启用，这使得账户可以通过 ERC-4337 bundler 执行用户操作，并可选择使用 paymaster 赞助 Gas。`SafeModuleSetup` 在 Safe 部署期间启用模块。模块针对 EntryPoint v0.7；EntryPoint v0.6 也部署用于旧版工具。

## Stable 网络设置

### 将 Stable 添加到您的钱包

**网络参数：**

- **网络名称：** Stable
- **链 ID：** 988
- **货币：** USDT0
- **RPC URL：** https://rpc.stable.xyz
- **区块浏览器：** https://stablescan.xyz

### 构建钱包集成

您可以通过以下方式添加 Stable 支持：

- 通过 Stable RPC 启用签名和 Gas 估算
- 支持 USDT 原生转账
- 为 dApp 集成 WalletConnect
- 将 Stable 添加到链列表或元数据注册表
