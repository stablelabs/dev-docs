## 1. 索引器

索引器将原始区块链数据转换为可搜索、可查询的格式。它们为仪表板、分析、钱包、区块浏览器和应用程序后端提供支持。

### Envio

Envio 是区块链应用程序的数据层。它通过单个 GraphQL API 提供实时和历史链上数据，具有原始高速访问和在 Envio Cloud 上托管。

**功能**

- 实时和历史链上数据
- 具有原始高速访问权限的单个 GraphQL API
- 在 Envio Cloud 上进行托管

**文档**

Envio 的 HyperIndex 本机支持索引任何 EVM 链，包括 Stable，开箱即用，使用您自己的 RPC 作为数据源。

[https://docs.envio.dev/](https://docs.envio.dev/)

### The Graph

为超过 75,000 个项目提供数据访问的去中心化索引协议。

**功能**

- Stable 的子图
- 基于 GraphQL 的查询
- 分布式索引网络

**文档**

按照此快速入门指南在几分钟内创建、部署和查询子图：

[https://thegraph.com/docs/en/developing/creating-a-subgraph/](https://thegraph.com/docs/en/developing/creating-a-subgraph/)

### Ormi Labs

Ormi 是下一代索引器，旨在大规模提供实时和历史区块链数据。

**功能**

- 链尖索引
- 亚秒级查询延迟
- 无代码功能

**文档**

开始使用 Ormi 查询实时数据：

[https://docs.ormilabs.com/subgraphs/quickstart](https://docs.ormilabs.com/subgraphs/quickstart)

了解如何实时查询 Stable 上的 USDT0 数据：

[https://docs.ormilabs.com/subgraphs/tutorials/query-usdt0](https://docs.ormilabs.com/subgraphs/tutorials/query-usdt0)

### Goldsky

高性能索引平台，提供即时子图和开发者工具。

**功能**

- 子图部署和管理
- 用于实时事件流的 Webhook 创建
- 多子图同步到外部数据库

**文档**

[https://docs.goldsky.com/introduction](https://docs.goldsky.com/introduction)

如需 24/7 支持，请联系 [support@goldsky.com](mailto:support@goldsky.com)。

### SQD

SQD 通过 Portal 提供 Stable 数据，Portal 是一个 HTTP 流 API，它返回解码的、模式类型化的表而不是原始链状态，因此您可以在不运行存档节点的情况下进行索引。需要自定义转换的团队使用 Squid 和 Pipes SDK 构建索引器，可自托管或在 SQD Cloud 上运行。

**功能**

- 通过单个 HTTP 端点进行区块、交易和日志的历史和实时流
- 覆盖 `stable-mainnet`（链 ID 988）和 `stable-testnet`（链 ID 2201）的已解码、模式化表
- 用于自定义索引器的 Squid 和 Pipes SDK，具有用于 Postgres、ClickHouse、MongoDB、SQLite 和 Parquet 的连接器
- 区块在到达 Portal 之前由 SQD Network 工作人员验证

:::note
Stable 数据集在 SQD 上是私有的。企业客户通过 SQD Private Portal 按请求获得访问权限，而不是通过公共网络。测试网覆盖范围从区块 39,381,701 开始，而不是创世区块。
:::

**文档**

阅读 Stable 覆盖详情、数据集 slug 和端点：

[https://sqd.dev/chains/stable/](https://sqd.dev/chains/stable/)

从 Portal 流式传输解码数据：

[https://docs.sqd.dev/en/portal/evm/quickstart](https://docs.sqd.dev/en/portal/evm/quickstart)

使用 Pipes SDK 构建自定义索引器：

[https://docs.sqd.dev/en/sdk/pipes-sdk/evm/quickstart](https://docs.sqd.dev/en/sdk/pipes-sdk/evm/quickstart)

**开始使用**：[联系 SQD](https://sqd.dev/contact/) 以获取 Stable 数据集的访问权限，然后从 Portal 流式传输或指向 SDK 索引器。

## 2. 分析提供商

分析工具可帮助团队跟踪网络活动、实际支付、仪表板、使用流程和合约交互。

### Allium

面向区块链生态系统中的工程师和分析师的基础数据平台。

**功能**

- 标准化的区块链数据集
- 面向分析团队的查询工具
- 企业数据基础设施

**文档**

开始使用 Allium 的数据平台和 API 资源：

[https://www.allium.so/](https://www.allium.so/)

**开始使用**：在 [allium.so](https://www.allium.so/) 注册以获取 API 访问权限，然后使用 REST API 查询标准化的 Stable 链上数据集。

### CoinMarketCap

全球最大的加密资产市场跟踪平台。

**功能**

- Stable 资产的价格跟踪
- 投资组合工具
- 市场数据 API

**文档**

探索 CMC API 和集成资源：

[https://coinmarketcap.com/api/](https://coinmarketcap.com/api/)

**开始使用**：在 [coinmarketcap.com/api](https://coinmarketcap.com/api/) 注册一个 API 密钥，并通过 REST API 查询 Stable 资产价格和市场数据。

### CoinGecko

全球最大的独立加密数据聚合器。

**功能**

- 市场列表和价格数据
- 历史分析
- 面向开发者的 API 访问

**文档**

访问 CoinGecko 的 API 文档：

[https://www.coingecko.com/en/api](https://www.coingecko.com/en/api)

**开始使用**：从 [coingecko.com/en/api](https://www.coingecko.com/en/api) 获取免费或专业版 API 密钥，并通过 REST API 查询 Stable 代币价格和市场数据。

### Dexscreener

去中心化场所的实时图表和分析。

**功能**

- 实时 DEX 图表
- 流动性和配对分析
- 交易仪表板

**文档**

探索 Dexscreener 的 API 端点和开发者工具：

[https://docs.dexscreener.com/](https://docs.dexscreener.com/)

**开始使用**：浏览 [Dexscreener API 文档](https://docs.dexscreener.com/)，查询基于 Stable 的 DEX 池的实时配对数据、流动性和交易活动。

### DeBank

以太坊和 EVM 生态系统的投资组合追踪器。

**功能**

- 钱包分析
- 交易摘要
- 跨链投资组合跟踪

**文档**

阅读 DeBank 的 API 参考和集成文档：

[https://docs.debank.com/](https://docs.debank.com/)

**开始使用**：注册 [DeBank Cloud](https://cloud.debank.com/) 以获取 API 密钥，并查询 Stable 钱包余额、交易历史和投资组合数据。

## 3. 合规和调查

合规和调查平台可帮助团队监控交易风险并追踪链上资金流向。

### Chainalysis

Chainalysis 通过其 [KYT](https://www.chainalysis.com/product/kyt/)、实体筛选产品和 [Reactor](https://www.chainalysis.com/product/reactor/) 支持 Stable。

在 Stable 上部署的新可互换代币和不可互换代币（例如遵循 ERC-20 和 ERC-721 等主要标准）会自动覆盖。

**功能**

- 通过 KYT 对 Stable 代币进行持续监控和可操作警报
- 对 Stable 进行实体筛选
- 对 Stable 代币进行资金流向跟踪和交易调查
- 自动覆盖遵循 ERC-20 和 ERC-721 等标准的新代币

**文档**

阅读 [Stable 集成公告](https://www.chainalysis.com/blog/stable-automatic-token-support/) 以了解覆盖详情。

[申请 Chainalysis 演示](https://www.chainalysis.com/request-a-demo/)。
