# SDK 퀵스타트

`@stablechain/sdk`를 설치하고, 개인 키로 서명된 클라이언트를 생성하고, Stable 테스트넷에서 USDT0 전송을 보내고, 메인넷 브릿지 견적을 가져옵니다. 총 소요 시간: 약 5분.

:::note
Stable은 USDT0을 가스 토큰으로 사용합니다. 거래를 위해서는 테스트넷 USDT0만 있으면 됩니다. 별도의 기본 자산을 자금으로 조달할 필요는 없습니다.
:::

## 전제 조건

- Node.js 20 이상
- 테스트넷 USDT0이 있는 테스트 개인 키. [테스트넷 지갑에 자금 조달하기](/ko/how-to/use-faucet)를 참조하세요.

## 1. 설치

```bash
mkdir stable-sdk-quickstart && cd stable-sdk-quickstart
npm init -y && npm pkg set type=module
npm install @stablechain/sdk viem dotenv
```

```text
added 3 packages, audited 4 packages in 2s
```

`type=module`은 아래 단계에서 최상위 `await`를 사용할 수 있게 합니다. 이것이 없으면 `tsx`는 스크립트를 거부합니다.

테스트 키를 저장합니다:

```bash
echo "PRIVATE_KEY=0xYOUR_TEST_KEY" > .env
```

## 2. 클라이언트 생성

`index.ts`를 생성합니다:

```ts
import "dotenv/config";
import { createStable, Network } from "@stablechain/sdk";
import { privateKeyToAccount } from "viem/accounts";

const account = privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`);

const stable = createStable({
  network: Network.Testnet,
  account,
});

console.log("Signer:", account.address);
```

```text
Signer: 0xYourAddress
```

`createStable`은 세 가지 서명 모드를 허용합니다: `account` (서버측, 위에 표시됨), `transport` (`custom(window.ethereum)`을 통한 브라우저 지갑), 또는 `walletClient` (사전 빌드된 viem `WalletClient`). 세 가지 모두에 대해서는 [viem과 함께 SDK 사용하기](/ko/how-to/sdk-with-viem)를 참조하세요.

## 3. USDT0 전송 보내기

`index.ts`에 추가합니다:

```ts
const { txHash } = await stable.transfer({
  from: account.address,
  to: "0x000000000000000000000000000000000000dEaD",
  amount: 0.001,
});

console.log("Transfer:", txHash);
```

실행합니다:

```bash
npx tsx index.ts
```

```text
Signer: 0xYourAddress
Transfer: 0x8f3a...2d41
```

[테스트넷 익스플로러](https://testnet.stablescan.xyz)에서 해시를 열어 확인합니다.

## 4. 브릿지 견적 요청

`bridge`에는 두 가지 경로가 있습니다: LayerZero를 통한 네이티브 USDT0 경로와 나머지 모든 것을 위한 LI.FI. 아래 견적은 USDT-to-USDT0 쌍이므로 LI.FI를 통해 진행되며, LI.FI는 Stable 메인넷을 지원하지만 테스트넷은 지원하지 않습니다. `quoteBridge`는 읽기 전용 호출이므로(서명, 가스, 자금 불필요), 동일한 키로 메인넷 브릿지를 미리 볼 수 있습니다. 추가합니다:

```ts
import { Chain } from "@stablechain/sdk";

const stableMainnet = createStable({
  network: Network.Mainnet,
  account,
});

const bridgeQuote = await stableMainnet.quoteBridge({
  fromChain: Chain.Ethereum,
  toChain: Chain.Stable,
  fromToken: "0xdAC17F958D2ee523a2206206994597C13D831ec7", // Ethereum의 USDT
  toToken: "0x779Ded0c9e1022225f8E0630b35a9b54bE713736", // Stable의 USDT0
  amount: 100,
});

console.log("Bridge quote:", bridgeQuote);
```

```text
Bridge quote: { toAmount: 99.73 }
```

견적을 `stableMainnet.bridge({ ...params, quote })`에 전달하여 실행합니다. SDK는 승인 및 체인 전환을 처리합니다.

대신 USDT0-to-USDT0 견적을 요청했다면, SDK는 네이티브 USDT0 경로를 택했을 것입니다: 프로토콜 수수료 없이 1:1이며, 견적은 감소된 `toAmount` 대신 LayerZero 메시지에 대한 `nativeFee` 및 `lzTokenFee`를 포함했을 것입니다. 해당 경로는 Sepolia 및 Stable 테스트넷에서도 작동합니다. `route: "usdt0"` 또는 `route: "lifi"`를 설정하여 하나를 강제할 수 있습니다. 트레이드오프 및 체인별 지원에 대해서는 [`BridgeRoute`](/ko/reference/sdk#bridgeroute)를 참조하세요.

## 5. 스왑

동일 체인 스왑은 동일한 패턴을 따릅니다. `stable.quoteSwap`은 Stable의 [Uniswap v3 풀](/ko/reference/dexes)에서 거래 가격을 책정하고 예상 출력과 미리 빌드된 트랜잭션을 반환합니다. `stable.swap({ ...params, quote })`은 ERC-20 승인을 내부적으로 처리하면서 이를 실행합니다. 이 예제는 4단계의 `stableMainnet` 클라이언트를 사용하여 메인넷에서 견적을 요청합니다. `quoteBridge`와 마찬가지로 읽기 전용입니다. 스왑은 테스트넷 Uniswap v3 배포에 대해 테스트넷에서도 작동합니다. 추가합니다:

```ts
const swapQuote = await stableMainnet.quoteSwap({
  fromToken: "0x779Ded0c9e1022225f8E0630b35a9b54bE713736", // USDT0
  toToken: "0xB8CE59FC3717ada4C02eaDF9682A9e934F625ebb", // XAUt0
  amount: 100,
});
console.log("Receive:", swapQuote.toAmount, "at least", swapQuote.toAmountMin);
```

```text
Receive: 0.0241 at least 0.0239
```

`toAmountMin`은 기본 0.5% 슬리피지 한도 이후의 출력입니다. `slippageBps`를 설정하여 변경할 수 있습니다.

:::note
풀이 쌍에 대한 유동성을 보유하지 않을 때, `quoteSwap` 및 `swap`은 `providerCode: "no_route"`와 함께 `StableQuoteError`를 발생시킵니다. 전체 API에 대해서는 [SDK 참조에서 `quoteSwap`](/ko/reference/sdk#quoteswapparams)을 참조하세요.
:::
