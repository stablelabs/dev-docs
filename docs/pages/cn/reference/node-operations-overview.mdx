## 节点类型

### 全节点
全节点维护区块链的完整副本，并验证所有交易和区块。全节点：
- 验证所有交易和区块
- 维护完整的区块链历史
- 可以为其他节点提供数据
- 支持网络的去中心化

### 归档节点
归档节点存储所有状态的完整历史记录，并可以提供历史查询。归档节点：
- 存储所有历史状态
- 支持任何区块高度的历史查询
- 需要显著更多的存储空间
- 对于区块浏览器和分析至关重要
