## 类别指南

- **用户钱包：** 这些是传统的面向消费者的钱包，例如移动应用程序、浏览器扩展程序或交易所关联钱包。它们允许用户持有 USDT、进行转账、连接到 dApp 并直接与 Stable 交互。
- **钱包 SDK：** 一种软件开发工具包，为开发者提供预构建的工具、API 和基础设施，以便将钱包创建、密钥管理、交易签名和区块链交互直接集成到他们的应用程序中。
- **托管 / 机构钱包：** 为机构提供受监管的企业级数字资产托管的平台。这些解决方案侧重于合规性、治理控制、安全密钥管理和资金操作，而不是最终用户流程。
- **嵌入式 / 应用内钱包：** 通过 SDK 或后端系统在应用程序内生成的钱包。这使得主流用户能够无缝入职，而无需安装或理解外部加密钱包。
- **智能钱包 / 账户抽象：** 支持自定义逻辑（例如无 Gas 交易、捆绑操作或自动执行）的可编程钱包。这些扩展了基本钱包功能，具有开发者定义的行为。
- **MPC 钱包提供商：** 使用多方计算 (MPC) 将私钥控制权分配给多个方或设备的密钥管理系统。非常适合需要高安全性托管而无需传统助记词的应用程序或企业。
- **连接提供商：** 连接钱包和 dApp 的协议，例如 WalletConnect (Reown)。它们不存储资产或充当钱包本身；相反，它们提供安全的通信通道用于交易签名和交互。

## 1. 用户钱包

这些是全球主要交易所提供的最终用户钱包。它们允许用户持有 USDT、转移资金并连接到 Stable 上的应用程序。

### Stable Pay

一个构建在 Stable 上的非托管支付钱包，专为快速、原生稳定币交易而设计。Stable Pay 提供即时 USDT 支付、可预测的费用和针对日常转账和商业优化的简单用户体验。

**功能**

- Stable 的非托管钱包
- 即时 USDT 支付
- 可预测且一致的交易成本
- 直接构建在 Stable 的 USDT 原生结算层上
- 专为支付和商业设计的消费者友好型 UI

### 币安钱包

一个广泛使用的多链钱包，与全球最大的交易量交易所集成。

**功能**

- 支持 Stable USDT
- 与币安生态系统直接集成
- 移动和扩展钱包选项

### Bitget 钱包

一个与 Bitget 交易所生态系统连接的多资产钱包，支持加密货币、股票和 ETF。

**功能**

- 支持 Stable USDT
- 内置 dApp 浏览器
- 与 Bitget 交易账户无缝集成

### Gate 钱包 (Gate Onchain)

由全球最大的现货交易所之一支持的钱包产品。

**功能**

- 支持 Stable USDT
- Gate 交易所与钱包之间的轻松转账
- dApp 和 Web 应用程序连接

### OKX 钱包 (OKX Onchain)

一个功能强大的全球多链钱包。

**功能**

- 支持 Stable USDT
- 深度 OKX 生态系统集成
- Web、移动和扩展钱包选项

### Atomic Wallet

一款非托管多资产钱包，可在桌面、移动设备和作为浏览器扩展使用。Atomic Wallet 集成了 [Simplex by Nuvei](/cn/reference/ramps#simplex-by-nuvei) 入口，因此用户可以通过应用程序内的 Simplex 使用银行卡、Apple Pay、Google Pay 或银行转账直接在 Stable 上购买 USDT。

**功能**

- 在 Stable 上持有、发送和接收 USDT
- 私钥本地存储在用户设备上
- 通过 Simplex 在应用程序内购买 Stable 上的 USDT 流程
- 适用于 Windows、macOS、Linux、iOS、Android 和 Chrome

**入门**：从 [atomicwallet.io](https://atomicwallet.io/downloads) 下载 Atomic Wallet，添加 Stable 作为网络，然后使用应用程序内的购买流程通过 Simplex 购买 Stable 上的 USDT。

## 2. 钱包 SDK

### Tether 钱包开发套件 (WDK)

Tether 的开源 SDK，用于在任何平台和区块链上构建自托管钱包。

**功能**

- 多链支持：比特币、以太坊、TON、TRON、Solana、Spark 等
- 代理钱包：原生支持 Stable 上的 AI 代理钱包和 x402 支付
- DeFi 集成：支持掉期、桥接和借贷协议的插件
- 可扩展设计：为新的区块链或协议添加自定义模块

**入门**：安装 [`@tetherto/wdk`](https://www.npmjs.com/package/@tetherto/wdk) 和 [`@tetherto/wdk-wallet-evm`](https://www.npmjs.com/package/@tetherto/wdk-wallet-evm)，然后按照 [WDK 文档](https://docs.wallet.tether.io) 将 Stable 配置为您的目标链。

## 4. 嵌入式 / 应用内钱包

通过 SDK 直接嵌入到应用程序中的钱包，实现无缝的用户入职和支付流程。

### Coinbase 开发者平台 (CDP)

CDP 为面向用户的应用程序和后端系统提供非托管钱包。用户身份验证钱包使用电子邮件、短信或社交登录。API 密钥钱包允许服务器管理账户，而 CDP 在受信任的执行环境中保护私钥。

**功能**

- 无助记词的嵌入式钱包
- 用于自动化工作流和后端服务的 API 密钥钱包
- EVM 账户创建和交易签名
- 用户控制钱包的密钥导出

**Stable 集成**

Coinbase 钱包 API 支持 Stable，因为它支持所有 EVM 兼容网络。将 Stable 配置为链 ID `988` 和 `https://rpc.stable.xyz`，或使用 CDP 签名并通过 Stable 的 RPC 广播。

Coinbase Onramp 是一款用于法币兑换加密货币的独立产品，不支持 Stable。

**入门**：按照 [CDP 非托管钱包文档](https://docs.cdp.coinbase.com/wallets/non-custodial-wallets/overview) 并选择用户身份验证或 API 密钥快速入门。

### Dynamic

企业级钱包基础设施，服务于数千个应用程序和超过 4000 万用户。

**功能**

- 钱包创建和身份验证
- 嵌入式钱包流程
- 应用程序和金融科技的用户入职

**入门**：按照 [Dynamic SDK 设置文档](https://docs.dynamic.xyz/introduction/welcome) 安装 SDK，并将 Stable 配置为应用程序中支持的网络。

### Privy

Privy 为用户、组织、资金库和代理提供嵌入式钱包。钱包可以使用非托管或托管配置。

**功能**

- 通过电子邮件、社交登录、Passkey 或外部钱包进行身份验证
- 嵌入式 EVM 钱包创建和交易签名
- 签名者、接收者、合同和转账金额的策略控制
- 用户控制非托管钱包的密钥导出

**入门**：按照 [Privy 嵌入式钱包文档](https://docs.privy.io/wallets/overview/embedded) 创建钱包，然后在应用程序中将 Stable 配置为 EVM 网络。

### Portal

Portal 通过适用于 Web、iOS、Android 和 React Native 的 SDK 提供 MPC 钱包，以及用于服务器端集成的 API。MPC（多方计算）将签名权限拆分到独立的密钥共享中。

**功能**

- 嵌入式 EVM 钱包创建、备份和恢复
- 消息和交易签名
- EVM 网络的自定义 RPC 配置
- Web、移动和 API 集成选项

**入门**：按照 [Portal SDK 快速入门](https://docs.portalhq.io/sdks/quickstart)，然后将 Stable 的 CAIP-2 链 ID (`eip155:988`) 映射到 `rpcConfig` 中的 `https://rpc.stable.xyz`。

### Turnkey

Turnkey 提供嵌入式钱包，其签名和策略评估在受信任的执行环境 (TEEs) 中进行。TEE 是一个隔离的、硬件支持的环境，用于在签名期间保护密钥。

**功能**

- 通过电子邮件、电话、社交登录、Passkey 或生物识别进行身份验证
- 跨 EVM 兼容网络的嵌入式钱包
- 非托管、托管和混合托管模型
- 可编程签名策略和每用户隔离

**入门**：按照 [Turnkey 嵌入式钱包概述](https://docs.turnkey.com/solutions/embedded-wallets/overview)，选择一个 SDK，并将 Stable 配置为 EVM 网络。

### Reown（前身为 WalletConnect）

连接钱包和应用程序的广泛采用标准。

**功能**

- 安全的钱包到 dApp 连接
- 支持移动、桌面和扩展钱包
- 广泛的生态系统兼容性

**用于钱包入职的 Reown SDK**

Stable 支持与 **Reown SDK** 集成，以帮助开发者为用户提供无缝的钱包和入职体验。

Reown 提供了一个开源的、一体化的 SDK，作为 WalletConnect 网络的官方网关。它支持在您的应用程序中实现流畅的钱包连接、交易、登录、嵌入式钱包（电子邮件和社交登录）、链上支付、应用内兑换等功能。

**入门**

- 访问 Reown 的文档：[https://docs.reown.com/overview](https://docs.reown.com/overview)

## Stable 网络设置

### 将 Stable 添加到您的钱包

**网络参数：**

- **网络名称：** Stable
- **链 ID：** 988
- **货币：** USDT0
- **RPC URL：** https://rpc.stable.xyz
- **区块浏览器：** https://stablescan.xyz

### 构建钱包集成

您可以通过以下方式添加 Stable 支持：

- 通过 Stable RPC 启用签名和 Gas 估算
- 支持 USDT 原生转账
- 为 dApp 集成 WalletConnect
- 将 Stable 添加到链列表或元数据注册表

## 您的钱包是否集成了 Stable？

您可以联系团队 [bizdev@stable.xyz](mailto:bizdev@stable.xyz) 以在此部分列出。
