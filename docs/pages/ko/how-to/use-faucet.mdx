# Stable 테스트넷 지갑에 자금을 충전하는 방법

Stable은 USDT0를 가스 토큰으로 사용하므로, 체인과 상호작용하기 위해서는 지갑에 USDT0가 필요합니다. 먼저 Faucet을 사용하여 계정에 USDT0를 충전해야 합니다.

1. https://faucet.stable.xyz 를 방문합니다
2. 'Get USDT0' 버튼을 클릭하면 1 USDT0가 지갑으로 전송됩니다.

## Sepolia에서 브릿지하기 (더 많은 수량)

더 많은 테스트 토큰이 필요하면 [USDT0를 Stable로 브릿지하기](/ko/tutorial/bridge-usdt0)를 따라 Sepolia에서 테스트 토큰을 발행하고 Stable 테스트넷으로 전송한 뒤 도착을 확인하세요.
