# 개요

Stable이 처음이신가요? 먼저 [빠른 시작](/ko/tutorial/quick-start)을 실행하세요. 5분이면 완료되며 테스트넷 트랜잭션을 전송하여 나머지 탭에서 연결할 수 있도록 합니다.

## 탐색

- [**계정**](/ko/explanation/accounts-overview): 지갑 생성, EIP-7702를 사용한 EOA 위임, 사용자 및 에이전트용 세션 키 범위 지정.
- [**결제**](/ko/explanation/payments-overview): USDT0 전송, P2P 및 구독 흐름 구축, ERC-3009로 인보이스 정산, x402로 API 가격 책정.
- [**계약**](/ko/explanation/contracts-overview): Solidity 계약 배포, 확인 및 인덱싱, Bank / Distribution / Staking 사전 컴파일 호출.
- [**AI 및 에이전트**](/ko/explanation/agent-settlement): MCP 서버를 AI 클라이언트에 연결하고 에이전트가 프롬프트를 통해 호출할 수 있는 x402 유료 도구를 노출합니다.

## 여기에서 시작하세요

- [**빠른 시작**](/ko/tutorial/quick-start): 테스트넷에 연결하고, 지갑에 자금을 지원하고, 첫 USDT0 트랜잭션을 전송합니다.
- [**첫 USDT0 전송**](/ko/tutorial/send-usdt0): TypeScript 예제와 함께 동일한 잔액에서 네이티브 및 ERC-20 전송.
- [**스마트 계약 배포**](/ko/tutorial/smart-contract): Foundry 스캐폴드, Stable 구성, Counter 계약 배포.
- [**도구 및 SDK**](/ko/explanation/tools-overview): 유형이 지정된 TypeScript SDK, 서비스 API, MCP 서버를 사용합니다.
