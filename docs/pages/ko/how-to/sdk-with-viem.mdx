# viem과 함께 SDK 사용하기

`@stablechain/sdk`는 viem을 기반으로 구축되었습니다. `createStable`은 세 가지 서명 모드를 허용하며, 코드가 실행되는 위치에 따라 하나를 선택합니다: 개인 키를 사용한 서버 측, 사용자 지갑을 사용한 브라우저 측, 또는 이미 구성한 `WalletClient`를 사용한 경우(예: wagmi 앱에서).

이 가이드에서는 각 모드를 처음부터 끝까지 보여줍니다.

## 서버 측: 개인 키 `Account`

viem의 `privateKeyToAccount`를 사용하여 백엔드에서 보유한 개인 키로 서명합니다.

```ts
import "dotenv/config";
import { createStable, Network } from "@stablechain/sdk";
import { privateKeyToAccount } from "viem/accounts";

const account = privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`);

const stable = createStable({
  network: Network.Mainnet,
  account,
});

const { txHash } = await stable.transfer({
  from: account.address,
  to: "0xRecipient",
  amount: 5,
});

console.log(txHash);
```

```text
0x8f3a...2d41
```

## 브라우저 측: 지갑의 `Transport`

`custom(window.ethereum)` (또는 모든 EIP-1193 제공자)을 `transport`로 전달합니다. SDK는 전송에서 `WalletClient`를 빌드하고 `transfer`에 전달하는 `from` 주소로 서명합니다.

```ts
import { createStable, Network } from "@stablechain/sdk";
import { custom } from "viem";

const stable = createStable({
  network: Network.Mainnet,
  transport: custom(window.ethereum),
});

const [from] = await window.ethereum.request({ method: "eth_requestAccounts" });

const { txHash } = await stable.transfer({
  from,
  to: "0xRecipient",
  amount: 5,
});
```

```text
0x8f3a...2d41
```

:::warning
전송 모드는 `transfer`만 처리합니다. `transfer`는 명시적인 `from`을 받기 때문입니다. `swap`, `quoteSwap`, `bridge` 및 `earn` 메서드는 서명자 주소를 `account` 또는 `walletClient`에서 읽고 둘 다 설정되지 않은 경우 `StableValidationError`를 발생시킵니다. 이러한 경우, 동일한 제공자로부터 `WalletClient`를 대신 빌드하십시오(다음 섹션).
:::

:::warning
브라우저 지갑을 사용하면 `transfer`, `bridge` 및 `swap`이 `switchChain`을 호출하여 지갑을 올바른 네트워크에 배치합니다. 사용자가 거부하면 SDK는 `phase: "switch_chain"`과 함께 `StableTransactionError`를 발생시킵니다. 이를 포착하고 사용자에게 재시도를 알리십시오. 개인 키 `account`는 전환을 건너뛰고 트랜잭션이 지정하는 체인에 서명합니다.
:::

## 자신만의 `WalletClient` 가져오기

`WalletClient`를 이미 가지고 있는 경우(예: wagmi 또는 사용자 지정 서명자에서), 직접 전달합니다. 이는 `account` 및 `transport`보다 우선합니다.

```ts
import { createStable, Network } from "@stablechain/sdk";
import { createWalletClient, custom } from "viem";
import { stable as stableChain } from "viem/chains";

const walletClient = createWalletClient({
  chain: stableChain,
  transport: custom(window.ethereum),
});

const [from] = await walletClient.requestAddresses();

const stable = createStable({
  network: Network.Mainnet,
  walletClient,
});

const { txHash } = await stable.transfer({ from, to: "0xRecipient", amount: 5 });
```

```text
0x8f3a...2d41
```

## 모드 선택

| **모드** | **사용 시점** |
| :--- | :--- |
| `account` | 백엔드 서비스, 스크립트, 에이전트, 키를 보유하고 있는 모든 곳. |
| `transport` | 명시적인 `from`으로 `transfer`만 호출하는 브라우저 앱. |
| `walletClient` | 이미 구성된 `WalletClient`가 있는 경우 (wagmi, RainbowKit, ConnectKit). |
