# 代币经济学

STABLE 是 Stable 主网的治理代币。它通过委托权益证明（delegated Proof-of-Stake）保障网络安全，管理协议升级，并使质押者有权获得验证者分发的 USDT0 Gas 收益份额。

## 概述

| 项目 | 详情 |
| :---- | :---- |
| **符号** | STABLE |
| **总供应量** | 100,000,000,000 个代币 |
| **标准** | ERC-20 (在 Stable 主网 EVM 上) |
| **小数位** | 18 |

STABLE 是 Stable 主网和生态系统的治理代币，旨在支持验证者、开发者和用户之间的长期经济协同。
## 代币分配

**总供应量：** 100,000,000,000 STABLE 代币

| 类别 | 分配比例 | STABLE 数量 |
| :---- | :---- | :---- |
| **投资者和顾问** | 25% | 25,000,000,000 |
| **团队** | 25% | 25,000,000,000 |
| **生态系统和社区** | 40% | 40,000,000,000 |
| **创世分配** | 10% | 10,000,000,000 |
| **总计** | 100% | 100,000,000,000 |

## 发行模型和供应计划

* 总供应量固定为 100,000,000,000 STABLE 代币。
* Stable 主网启动时，只有一部分供应进入流通。
* 团队和投资者及顾问的分配遵循一年锁定期，之后进行线性解锁，以确保长期承诺。

## 分配情况

### 创世分配 - 占代币总供应量的 10%

* 旨在启动使用、为市场提供流动性、进行空投活动、奖励早期支持者以及与交易所和生态系统伙伴合作开展活动。

    **归属时间表**
    * 在 Stable 主网启动时 100% 解锁

### 生态系统与社区 - 占代币总供应量的 40%

支持长期的生态系统和社区增长：

* 支持 Stable 软件和生态系统的开发
* 开发者资助
* 用户 onboarding 激励
* 支付伙伴集成
* 链上活动奖励
* 黑客松、大使计划
* 基础设施资助

  **归属时间表**
  * **初始解锁：** 在 Stable 主网启动时解锁总供应量的 8%。这些代币用于为战略启动伙伴提供激励、满足流动性需求以及支持早期生态系统增长活动。

### 团队 - 占代币总供应量的 25%

* 分配给创始团队成员、工程师、研究人员和贡献者
* 旨在确保团队与 Stable 生态系统之间的长期协同。

    **归属时间表**
    * **1 年锁定期：** 前 24 个月不解锁任何代币

### 投资者与顾问 - 占代币总供应量的 25%

* 用于融资轮次和顾问支持。

    **归属时间表**
    * **1 年锁定期：** 前 24 个月不解锁任何代币

## 经济设计原则

Stable 的代币经济学围绕三个基本目标设计：

### 1. 为支付优化的 Layer 1 提供动力

STABLE 代币激励高吞吐量、低延迟的基础设施，支持亚秒级区块确认和企业结算保证。

### 2. 支持可持续的生态系统增长

总代币供应量的 40% 用于长期增长，重点关注关键开发和增长领域。

* 开发者资助
* 伙伴集成
* 新的生态系统应用

### 3. 通过归属机制调整长期贡献者

团队分配采用一年锁定期，之后进行线性解锁，确保长期协同并持续为网络开发做出贡献。

## STABLE 代币的用途

STABLE 代币是 Stable 主网上的 ERC-20 治理代币。它可用于：

* 选举验证者
* 对协议升级进行投票
* 处理治理提案
* 作为从验证者处接收 Gas 费分配的凭证

在 Stable 网络上，所有交易都使用 USDT0 作为原生 Gas 代币。这些 USDT0 Gas 费被收集到一个由智能合约管理的金库中。当代币持有者将他们的 STABLE 代币质押给验证者时，验证者可以选择按比例将金库中的 Gas 费分配给质押者。
