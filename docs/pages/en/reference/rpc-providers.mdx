## Alchemy

A complete blockchain development platform trusted globally. [Get started with Alchemy](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable)

**Capabilities**

- RPC + WebSocket infrastructure
- Monitoring dashboards
- Developer APIs and SDKs

**Get started**: Create a Stable app in the [Alchemy dashboard](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable) to get an RPC URL, then use it as your JSON-RPC endpoint.

## Chainstack

Chainstack provides managed RPC nodes for Stable. You can connect to a deployed node over HTTPS or WebSocket.

**Capabilities**

- Managed RPC nodes
- HTTPS and WebSocket endpoints
- Full and archive node access

**Get started**: Create a project in the [Chainstack console](https://console.chainstack.com/), select Stable, and deploy a node. Copy its HTTPS or WebSocket endpoint into your application.

## Goldsky Edge RPC

Goldsky Edge RPC is a managed RPC endpoint for Stable Mainnet and Testnet, served from several regions. It is built on [eRPC](https://github.com/erpc/erpc), an open-source RPC proxy that you can also run yourself.

**Capabilities**

- HTTPS JSON-RPC endpoints (no WebSocket)
- Caching of chain data
- Usage, latency, and error dashboards

**Get started**: Create an API key in the [Goldsky dashboard](https://app.goldsky.com), then send JSON-RPC requests to `https://edge.goldsky.com/standard/evm/988?key=YOUR_KEY`. Use chain ID `2201` for Testnet.

## PublicNode

PublicNode by Allnodes provides free public RPC endpoints for Stable without requiring an account.

**Capabilities**

- EVM JSON-RPC and WebSocket endpoints, free with no sign-up
- Cosmos RPC, REST and gRPC-Web endpoints
- Pruned and archive node snapshots at [publicnode.com/snapshots](https://www.publicnode.com/snapshots#stable)

**Get started**: Copy an endpoint from [stable.publicnode.com](https://stable.publicnode.com) into your application, for example `https://stable-evm-rpc.publicnode.com` for EVM JSON-RPC.

## Tenderly

A full-stack developer platform offering simulation, debugging, monitoring, and execution tooling.

**Capabilities**

- Real-time contract simulation
- Debugging and tracing
- Transaction workflows for devs

**Get started**: Set up a Stable project in the [Tenderly dashboard](https://tenderly.co/) to access simulation, debugging, and transaction tracing for your contracts.
