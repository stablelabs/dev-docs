# 如何为您的 Stable 测试网钱包充值

Stable 使用 USDT0作为燃料代币，因此您需要在钱包中有 USDT0 才能与链进行交互。首先，您需要使用水龙头为您的账户充值 USDT0。

1. 访问 https://faucet.stable.xyz
2. 点击"Get USDT0"按钮，1 USDT0 将被投放到您的钱包中。

## 从 Sepolia 桥接（较大金额）

如需更多测试代币，请参阅[将 USDT0 桥接到 Stable](/cn/tutorial/bridge-usdt0)，在 Sepolia 铸造测试代币，将其桥接到 Stable 测试网并确认到账。
