# SDK 레퍼런스

`@stablechain/sdk`의 모든 표면입니다. 여기에는 [`createStable`](#createstableconfig)의 서명 클라이언트, [`createStableReader`](#createstablereaderconfig)의 읽기 전용 클라이언트, 공유 열거형, 상수 및 오류 클래스가 포함됩니다. 자세한 내용은 [SDK 퀵스타트](/ko/tutorial/sdk-quickstart)를 참조하십시오. 작업 중심의 수익 가이드는 [SDK로 수익 얻기](/ko/how-to/earn-yield)를 참조하십시오.

## 설치

```bash
npm install @stablechain/sdk viem
```

```text
added 2 packages, audited 3 packages in 2s
```

`viem >= 2.0.0`은 피어 종속성입니다. 이 패키지는 [`@stablechain/sdk`](https://www.npmjs.com/package/@stablechain/sdk)로 게시됩니다.

:::note
네이티브 USDT0 브리지 경로와 `bridge`의 `route` 매개변수는 버전 1.0.4 이상이 필요합니다. Uniswap v3 스왑은 버전 1.1.0 이상이 필요합니다. 이전 버전에서는 `bridge`, `quoteSwap`, `swap`이 항상 LI.FI를 통해 이루어집니다. `npm ls @stablechain/sdk`를 실행하여 현재 버전을 확인하십시오.
:::

## `createStable(config)`

`StableClient`를 구성합니다. [`StableClient`](#stableclient)에 나열된 메서드가 포함된 객체를 반환합니다.

```ts
import { createStable, Network } from "@stablechain/sdk";

const stable = createStable({ network: Network.Mainnet, account });
```

```text
StableClient { transfer, quoteBridge, bridge, quoteSwap, swap, earn }
```

### `StableConfig`

| **필드** | **유형** | **기본값** | **설명** |
| :--- | :--- | :--- | :--- |
| `network` | `Network` | `Network.Mainnet` | 대상 네트워크. |
| `rpc` | `string` | `network`의 공개 RPC | RPC 재정의. |
| `account` | `viem.Account` | | 서버 측 서명자(예: `privateKeyToAccount`). |
| `transport` | `viem.Transport` | | 브라우저-지갑 전송(예: `custom(window.ethereum)`). |
| `walletClient` | `viem.WalletClient` | | 사전 빌드된 지갑 클라이언트. `account` 및 `transport`보다 우선합니다. |
| `earn` | `{ vault: string }` | | Morpho V2 볼트 구성. `stable.earn`의 입금, 인출, 상환 및 calldata 준비 메서드를 호출하는 데 필요합니다. |
| `merklApiBase` | `string` | `https://api.merkl.xyz` | Merkl 보상 API 기본 URL. 자체 서버를 통해 프록시하여 브라우저 CORS 제한을 피하려면 재정의하십시오. |

`account`, `transport`, `walletClient` 중 하나를 제공하십시오. `earn` 필드는 선택 사항입니다. 이 필드 없이도 전송, 브리지, 스왑이 작동합니다. 볼트 입금 및 인출에는 이 필드가 필요하며, 구성된 볼트 없이 호출하면 SDK가 `StableValidationError`를 발생시킵니다.

## `StableClient`

### `transfer(params)`

네이티브 USDT0 또는 Stable의 모든 ERC-20을 보냅니다. 지갑을 Stable 체인으로 전환하고, 누락된 경우 온체인에서 토큰 소수 자릿수를 가져오며, 영수증을 기다립니다.

```ts
const { txHash } = await stable.transfer({
  from: "0xYourAddress",
  to: "0xRecipient",
  amount: 10,
});
```

```text
{ txHash: "0x8f3a...2d41" }
```

| **매개변수** | **유형** | **설명** |
| :--- | :--- | :--- |
| `from` | `string` | 발신자 주소. |
| `to` | `string` | 수신자 주소. |
| `amount` | `number` | 사람이 읽을 수 있는 금액. |
| `token` | `string?` | ERC-20 컨트랙트 주소. 네이티브 USDT0의 경우 생략. |
| `tokenDecimals` | `number?` | 소수 자릿수. 생략 시 온체인에서 가져옴. |

`OperationResult` (`{ txHash, toAmount? }`)를 반환합니다.

### `quoteBridge(params)`

브리지를 미리 봅니다. 읽기 전용. 서명 없음, 가스 없음.

```ts
const quote = await stable.quoteBridge({
  fromChain: Chain.Ethereum,
  toChain: Chain.Stable,
  fromToken: "0xdAC17F958D2ee523a2206206994597C13D831ec7", // 이더리움의 USDT
  toToken: "0x779Ded0c9e1022225f8E0630b35a9b54bE713736", // Stable의 USDT0
  amount: 100,
});
```

```text
{ toAmount: 99.73 }
```

`BridgeQuote`를 반환합니다. 반환되는 필드는 견적을 제공한 경로에 따라 달라집니다.

| **필드** | **유형** | **설명** |
| :--- | :--- | :--- |
| `toAmount` | `number?` | 대상 금액. USDT0 경로에서는 항상 `amount`와 동일합니다(1:1, 프로토콜 수수료 없음). LI.FI 경로에서는 애그리게이터의 수수료 및 슬리피지를 제외한 순액입니다. |
| `nativeFee` | `bigint?` | LayerZero 메시징 수수료, 소스 체인의 가스 토큰 wei 단위. USDT0 경로만 해당. |
| `lzTokenFee` | `bigint?` | LZ 토큰으로 지불 가능한 수수료, wei 단위. USDT0 경로만 해당. SDK는 `payInLzToken: false`로 견적을 내므로, 이 값은 `0n`입니다. |

USDT0 경로에서 `quoteBridge`는 소스 OFT 어댑터에서 `quoteSend`를 호출합니다. 실패하면 `StableQuoteError`와 `provider: "layerzero"`가 발생합니다.

:::note
위 예시는 USDT에서 USDT0으로 견적을 내는데, 이는 LI.FI 경로입니다. LI.FI는 [`Chain`](#chain) 열거형의 메인넷 체인에 대해서만 견적을 제공합니다. `Chain.Sepolia` 및 `Chain.StableTestnet`은 `StableQuoteError`로 거부되며, `CHAIN_CONFIGS`의 일부 토큰 주소(예: 이더리움의 USDT0)는 LI.FI의 견적 거부 목록에 있습니다. 의심스러우면 체인의 캐노니컬 토큰으로 견적을 내십시오.

USDT0 경로는 이러한 제한이 없습니다. OFT 어댑터에 대해 온체인에서 견적을 내므로 `Chain.Sepolia` 및 `Chain.StableTestnet`에서도 작동합니다.
:::

### `bridge(params)`

네이티브 USDT0 OFT 경로 또는 LI.FI 애그리게이터를 통해 토큰을 크로스체인으로 브리지합니다. SDK는 ERC-20 승인을 처리하고, 전송하기 전에 지갑을 소스 체인으로 전환합니다. 내부 견적 호출을 건너뛰려면 미리 가져온 `quote`를 전달하십시오.

```ts
const { txHash } = await stable.bridge({ ...bridgeParams, quote });
```

```text
{ txHash: "0xabcd...7890" }
```

| **매개변수** | **유형** | **설명** |
| :--- | :--- | :--- |
| `fromChain` | `Chain` | 소스 체인. |
| `toChain` | `Chain` | 대상 체인. `fromChain`과 달라야 합니다. |
| `fromToken` | `string` | 소스 토큰 컨트랙트 주소. |
| `toToken` | `string` | 대상 토큰 컨트랙트 주소. |
| `amount` | `number` | 사람이 읽을 수 있는 금액. |
| `route` | `BridgeRoute?` | 사용할 브리지. 기본값은 `"auto"`입니다. [`BridgeRoute`](#bridgeroute)를 참조하십시오. |
| `fromDecimals` | `number?` | 소스 토큰 소수 자릿수. 기본값은 `6`입니다. LI.FI 경로만 해당. USDT0 경로는 `CHAIN_CONFIGS`에서 소수 자릿수를 읽습니다. |
| `recipient` | `string?` | 대상 주소. 기본값은 서명자입니다. |
| `quote` | `BridgeQuote?` | 미리 가져온 견적. 내부 견적 호출을 건너뜁니다. |

USDT0 경로에서 `bridge`는 현재 허용량이 부족할 때 소스 USDT0을 OFT 어댑터에 승인한 다음, LayerZero 수수료를 `msg.value`로 첨부하여 `send`를 호출합니다. 환불 주소는 서명자입니다.

### `quoteSwap(params)`

거래를 보내지 않고 Stable에서 스왑을 견적합니다. 기본적으로 SDK는 [캐노니컬 Uniswap v3 배포](/ko/reference/dexes), 즉 [Stable Swap](https://swap.stable.xyz)의 배후 컨트랙트에서 거래 가격을 책정합니다. 직접 풀의 모든 수수료 티어에 대해 `QuoterV2`를 호출하고, USDT0을 통한 두 풀 경로도 포함하여 최상의 출력을 유지합니다. 풀 수수료와 가스는 지불하지만, 애그리게이터 수수료는 없습니다.

```ts
const quote = await stable.quoteSwap({
  fromToken: "0x779Ded0c9e1022225f8E0630b35a9b54bE713736", // USDT0
  toToken: "0xB8CE59FC3717ada4C02eaDF9682A9e934F625ebb", // XAUt0
  amount: 100,
  slippageBps: 50, // 0.5%, 기본값
});
```

```text
{ route: "uniswap", toAmount: 0.0241, toAmountMin: 0.0239, path: [{ tokenIn: "0x779D...", tokenOut: "0xB8CE...", fee: 500 }], fromAmount: 100000000n, fromToken: "0x779D...", approvalAddress: "0x32ea...", transactionRequest: { ... } }
```

견적에는 서명되지 않은 거래와 승인할 스펜더가 포함됩니다. 백엔드는 견적을 내고 `transactionRequest`를 지갑이나 [가스 면제](/ko/explanation/gas-waiver)에 전달할 수 있습니다. 거래의 마감 기한은 견적 후 20분입니다.

`SwapQuote`를 반환합니다.

| **필드** | **유형** | **설명** |
| :--- | :--- | :--- |
| `route` | `"uniswap" \| "lifi"` | 견적이 빌드된 장소. |
| `toAmount` | `number` | 예상 출력, `toToken` 소수 자릿수로 포맷됨. |
| `toAmountMin` | `number?` | 슬리피지 후 허용되는 최소 출력. Uniswap 경로만 해당. |
| `path` | `{ tokenIn, tokenOut, fee }[]?` | 거래가 통과하는 풀. Uniswap 경로만 해당. |
| `fromAmount` | `bigint` | 원시 소스 금액. |
| `fromToken` | `string` | 승인할 ERC-20. |
| `approvalAddress` | `string?` | ERC-20 승인을 위한 스펜더(Uniswap 경로에서 `SwapRouter02`). |
| `transactionRequest` | `{ to, data, value, gasLimit, chainId }` | 서명되지 않은 스왑 거래. `gasLimit`은 Uniswap 경로에서 `""`입니다. 승인 후 지갑이 가스를 추정합니다. |

유동성이 없는 풀이 있는 쌍은 `StableQuoteError`와 `provider: "uniswap"` 및 `providerCode: "no_route"`를 발생시킵니다.

:::note
Stable의 Uniswap v3 풀의 유동성은 아직 많은 쌍에서 부족합니다. 사용자에게 `toAmount`를 표시하기 전에 참조 가격과 비교하여 확인하고, `slippageBps`를 타이트하게 유지하십시오.
:::

### `swap(params)`

Stable에서 토큰을 스왑합니다. `quoteSwap`과 동일한 라우팅을 사용하고, 허용량이 부족할 때 정확한 금액에 대해 라우터를 승인하며, 영수증을 기다립니다. 견적을 건너뛰려면 미리 가져온 `quote`를 전달하십시오. 토큰을 다른 체인으로 이동하려면 [`bridge`](#bridgeparams)를 사용하십시오.

```ts
const quote = await stable.quoteSwap({ fromToken, toToken, amount: 100 });
const { txHash, toAmount } = await stable.swap({ fromToken, toToken, amount: 100, quote });
```

```text
{ txHash: "0xabcd...", toAmount: 0.0241 }
```

| **매개변수** | **유형** | **기본값** | **설명** |
| :--- | :--- | :--- | :--- |
| `fromToken` | `string` | | Stable의 소스 ERC-20 주소. 네이티브 USDT0의 경우 USDT0 ERC-20 주소를 사용하십시오. |
| `toToken` | `string` | | Stable의 대상 ERC-20 주소. |
| `amount` | `number` | | 사람이 읽을 수 있는 금액. |
| `fromDecimals` | `number?` | 온체인 | 소스 토큰 소수 자릿수. Uniswap 경로에서는 토큰에서 읽습니다. LI.FI 경로에서는 기본값 `6`입니다. |
| `toAddress` | `string?` | 서명자 | 수신자 주소. |
| `route` | `SwapRoute?` | `"auto"` | 장소. [`SwapRoute`](#swaproute)를 참조하십시오. |
| `slippageBps` | `number?` | `50` | 기본 포인트 단위의 최대 슬리피지. `toAmountMin`을 설정합니다. Uniswap 경로만 해당. |
| `quote` | `SwapQuote?` | | 미리 가져온 견적. 견적을 건너뜁니다. 견적의 `route`와 충돌하는 `route`는 `StableValidationError`를 발생시킵니다. |

## `SwapRoute`

`type SwapRoute = "auto" | "uniswap" | "lifi"`. `swap` 및 `quoteSwap`에서 `route` 매개변수를 통해 설정합니다.

| **값** | **동작** |
| :--- | :--- |
| `"auto"` | 기본값. `"uniswap"`과 동일. |
| `"uniswap"` | Stable의 캐노니컬 Uniswap v3 배포. `QuoterV2`로 온체인에서 견적을 내고 `SwapRouter02`를 통해 `slippageBps` 제한과 20분 마감 기한으로 스왑합니다. 메인넷 및 테스트넷에서 작동. |
| `"lifi"` | LI.FI 애그리게이터. LI.FI의 수수료(기본값 0.25%)를 추가하고, 메인넷만 지원하며, Stable에서 제한된 DEX 범위를 가집니다. |

SDK는 다음 배포를 사용합니다.

| **네트워크** | **`QuoterV2`** | **`SwapRouter02`** |
| :--- | :--- | :--- |
| 메인넷 | `0xb070179E7032CdA868b53e6C1742F80c9e940d1A` | `0x32eaf9B5d5F2CD7361c5012890C943D7de84C22a` |
| 테스트넷 | `0x8034456f896C0FcC7559D7641BDA4560fEabFBCb` | `0x42657399bD6ACcd22f67568AAf7Bf523c0271737` |

## `BridgeRoute`

`type BridgeRoute = "auto" | "usdt0" | "lifi"`. `bridge` 및 `quoteBridge`에서 `route` 매개변수를 통해 설정합니다. 1.0.4에서 추가되었습니다.

| **값** | **동작** |
| :--- | :--- |
| `"auto"` | 기본값. 두 체인 모두 아웃바운드 OFT 어댑터를 가지고 있고 `fromToken` / `toToken`이 각 체인의 USDT0일 때 USDT0 경로를 사용합니다. 그렇지 않으면 LI.FI로 폴백합니다. |
| `"usdt0"` | 네이티브 USDT0 LayerZero OFT 경로를 강제합니다. 쌍에 어댑터가 없거나 토큰이 USDT0이 아닐 때, 수수료를 부과하는 경로로 자동으로 폴백하지 않고 `StableValidationError`를 발생시킵니다. |
| `"lifi"` | LI.FI 애그리게이터를 강제합니다. 비 USDT0 토큰, 어댑터가 없는 체인, 또는 빠른 경로를 원하고 수수료를 허용할 때 사용하십시오. |

두 경로는 비용과 속도를 교환합니다.

| | **USDT0 (LayerZero OFT)** | **LI.FI** |
| :--- | :--- | :--- |
| 메커니즘 | 소스에서 소각, 대상에서 발행 | 브리지 및 DEX에 걸쳐 집계 |
| 토큰 | USDT0에서 USDT0만 | LI.FI가 지원하는 모든 쌍 |
| 수령 금액 | 1:1, 프로토콜 수수료 없음 | 견적, 수수료 및 슬리피지 제외 순액 |
| 지불 금액 | 소스 가스 + LayerZero 메시징 수수료(`nativeFee`) | 소스 가스 + 애그리게이터 수수료 |
| 속도 | 느림, DVN 검증 대기 | 빠름 |
| 테스트넷 | Sepolia 및 Stable 테스트넷에서 작동 | 메인넷 체인만 |

```ts
const bridgeParams = {
  fromChain: Chain.Ethereum,
  toChain: Chain.Stable,
  fromToken: "0x6C96dE32CEa08842dcc4058c14d3aaAD7Fa41dee", // 이더리움의 USDT0
  toToken: "0x779Ded0c9e1022225f8E0630b35a9b54bE713736", // Stable의 USDT0
  amount: 100,
  route: "usdt0" as const,
};

const quote = await stable.quoteBridge(bridgeParams);
const { txHash, toAmount } = await stable.bridge({ ...bridgeParams, quote });
```

```text
{ txHash: "0xabcd...7890", toAmount: 100 }
```

### USDT0 경로의 체인

`"auto"`는 OFT 어댑터가 배포된 체인에서만 USDT0 경로를 선택합니다. 나머지는 LI.FI로 폴백합니다.

| **체인** | **USDT0 경로** |
| :--- | :--- |
| `Chain.Stable` | 예 |
| `Chain.Ethereum` | 예 |
| `Chain.Arbitrum` | 예 |
| `Chain.Ink` | 예 |
| `Chain.Bera` | 예 |
| `Chain.MegaETH` | 예 |
| `Chain.HyperEVM` | 예 |
| `Chain.StableTestnet` | 예 |
| `Chain.Sepolia` | 예 |
| `Chain.Base` | 아니요, LI.FI만 |
| `Chain.BSC` | 아니요, LI.FI만 |

:::note
이 표를 하드코딩하는 대신 `BRIDGE_CHAIN_CONFIGS`를 읽으십시오. `oftAdapter` 및 `lzOutbound !== false` 항목이 있는 엔트리는 USDT0 경로를 통해 보낼 수 있습니다.
:::

## `stable.earn`

Morpho V2 볼트에 USDT0을 공급하여 수익을 얻고, Merkl 인센티브 보상을 청구합니다. 모든 메서드는 `earn` 네임스페이스에 있으며 서명자가 필요합니다. 입금, 인출, 상환 및 calldata 준비 메서드에는 [`StableConfig`](#stableconfig)에 `earn: { vault }`도 필요합니다.

```ts
const stable = createStable({
  network: Network.Mainnet,
  account,
  earn: { vault: "0xb7Df8db22A5DBBFA9ebeb94b3910aec6a4f05c08" },
});
```

```text
stable.earn { deposit, bulkDeposit, withdraw, bulkWithdraw, redeem, forceWithdraw, forceRedeem, prepareDepositCalldata, prepareWithdrawCalldata, prepareRedeemCalldata, incentiveRewards }
```

금액 및 공유 수는 사람이 읽을 수 있는 숫자입니다. 자산 및 공유 소수 자릿수는 생략 시 온체인에서 가져옵니다. 입금, 인출, 상환 및 강제 메서드는 `EarnResult` (`{ txHash, idempotencyKey? }`)를 반환하고 영수증을 기다린 후 해결됩니다. 대량 메서드는 `BulkEarnResult`를 반환하고 `incentiveRewards.claim()`은 `MerklClaimResult`를 반환합니다(아래 섹션에서 설명).

### `deposit(params)`

자산을 볼트에 공급합니다. ERC-20 승인(또는 지갑이 지원하는 경우 허가 서명)을 처리한 다음, 입금을 한 번의 호출로 처리합니다.

```ts
const { txHash } = await stable.earn.deposit({ amount: 100 });
```

```text
{ txHash: "0x8f3a...2d41" }
```

| **매개변수** | **유형** | **기본값** | **설명** |
| :--- | :--- | :--- | :--- |
| `amount` | `number` | | 입금할 기본 자산, 사람이 읽을 수 있는 형식. |
| `vault` | `string?` | 구성 볼트 | 볼트 주소 재정의. 여러 볼트에 걸쳐 `bulkDeposit`의 항목별로 필요합니다. |
| `tokenDecimals` | `number?` | 온체인 | 기본 자산 소수 자릿수. |
| `slippageTolerance` | `number?` | `0.0003` | 소수점 형식의 슬리피지(예: `0.003` = 0.3%). Morpho의 기본 0.03%로 설정됩니다. |
| `depositBuffer` | `number?` | | 이 입금이 소비할 수 있는 볼트 유휴 유동성의 최대 비율(예: `0.8` = 80%). `> 0` 및 `≤ 1`이어야 합니다. 초과 시 전송 전에 오류가 발생합니다. |
| `idempotencyKey` | `string?` | | 중복 제거 키. 진행 중인 키로 두 번째 호출을 하면 동일한 Promise가 반환됩니다. |

### `withdraw(params)`

주어진 양의 기본 자산을 인출합니다. 유휴 볼트 유동성이 부족하면 SDK는 자동으로 볼트의 어댑터에서 할당을 해제하여 차액을 충당합니다.

```ts
const { txHash } = await stable.earn.withdraw({ amount: 50 });
```

```text
{ txHash: "0xabcd...7890" }
```

| **매개변수** | **유형** | **기본값** | **설명** |
| :--- | :--- | :--- | :--- |
| `amount` | `number` | | 인출할 기본 자산, 사람이 읽을 수 있는 형식. |
| `tokenDecimals` | `number?` | 온체인 | 기본 자산 소수 자릿수. |
| `idempotencyKey` | `string?` | | 중복 제거 키. |

### `redeem(params)`

주어진 수의 볼트 공유를 기본 자산으로 상환합니다. `withdraw`와 마찬가지로 유휴 유동성이 부족하면 어댑터에서 자동으로 할당을 해제합니다.

```ts
const { txHash } = await stable.earn.redeem({ shares: 25 });
```

```text
{ txHash: "0xabcd...7890" }
```

| **매개변수** | **유형** | **기본값** | **설명** |
| :--- | :--- | :--- | :--- |
| `shares` | `number` | | 상환할 볼트 공유, 사람이 읽을 수 있는 형식. |
| `shareDecimals` | `number?` | 온체인 | 볼트 공유 소수 자릿수. |
| `idempotencyKey` | `string?` | | 중복 제거 키. |

### `bulkDeposit(items, options?)` / `bulkWithdraw(items, options?)`

여러 입금 또는 인출을 순차적으로 실행합니다. 기본적으로 배치는 모든 항목을 시도하고 부분 결과를 반환합니다. 첫 번째 실패 시 중단하고 `StableBulkError`를 발생시키려면 `stopOnError: true`로 설정하십시오.

```ts
const result = await stable.earn.bulkDeposit([
  { amount: 100 },
  { amount: 250, vault: "0xAnotherVault" },
]);
```

```text
{ results: [ { status: "fulfilled", txHash: "0x..." }, ... ], succeeded: 2, failed: 0 }
```

`items`는 `EarnDepositParams` (또는 `EarnWithdrawParams`) 배열입니다. `options`는 다음을 허용합니다.

| **옵션** | **유형** | **기본값** | **설명** |
| :--- | :--- | :--- | :--- |
| `idempotencyKey` | `string?` | | 배치 수준 중복 제거 키. |
| `stopOnError` | `boolean?` | `false` | 부분 결과를 반환하는 대신 첫 번째 실패 시 중단하고 `StableBulkError`를 발생시킵니다. |

`BulkEarnResult` (`{ results, succeeded, failed, idempotencyKey? }`)를 반환합니다. `results`의 각 항목은 `{ status: "fulfilled", txHash, vault?, idempotencyKey? }` 또는 `{ status: "rejected", error, vault?, idempotencyKey? }`입니다.

### `forceWithdraw(params)` / `forceRedeem(params)`

어떤 어댑터 포지션을 먼저 할당 해제할지 명시적으로 제어하여 인출 또는 상환합니다. `withdraw` / `redeem`의 자동 선택 대신 직접 소스 시장을 선택해야 할 때 이 기능을 사용하십시오.

```ts
const { txHash } = await stable.earn.forceWithdraw({
  amount: 1000,
  deallocations: [{ adapter: "0xAdapter", amount: 1000 }],
});
```

```text
{ txHash: "0xabcd...7890" }
```

두 메서드 모두 `deallocations: ForceDeallocation[]` 배열과 선택적 `tokenDecimals`(할당 해제 금액에 사용되는 기본 자산 소수 자릿수; 생략 시 온체인에서 가져옴)를 받습니다. `forceWithdraw`는 `amount`를 받고, `forceRedeem`은 `shares`와 선택적 `shareDecimals`를 받습니다. 각 `ForceDeallocation`은 다음과 같습니다.

| **필드** | **유형** | **설명** |
| :--- | :--- | :--- |
| `adapter` | `string` | 할당 해제할 어댑터 컨트랙트. |
| `amount` | `number` | 기본 자산 단위로 할당 해제할 금액. |
| `marketParams` | `object?` | Morpho Blue 시장 어댑터에만 필요: `{ loanToken, collateralToken, oracle, irm, lltv }` (`lltv`는 1e18로 스케일링됨). 볼트 어댑터의 경우 생략. |

### `prepareDepositCalldata(params)` / `prepareWithdrawCalldata(params)` / `prepareRedeemCalldata(params)`

서명하거나 보내지 않고 거래 calldata를 빌드합니다. 이를 사용하여 릴레이어, 가스 면제 흐름 또는 멀티시그를 통해 거래를 라우팅합니다.

```ts
const { steps, chainId } = await stable.earn.prepareDepositCalldata({ amount: 100 });
```

```text
{ steps: [ { to: "0x...", data: "0x...", value: 0n } ], chainId: 988 }
```

`prepareDepositCalldata`는 `EarnDepositCalldata` (`{ steps, chainId }`)를 반환하며, 여기서 `steps`는 `{ to, data, value }` 트랜잭션의 정렬된 목록입니다. 이는 선택적 토큰 승인과 이은 입금입니다. `prepareWithdrawCalldata` 및 `prepareRedeemCalldata`는 `EarnWithdrawCalldata` (`{ to, data, value, chainId }`)를 반환하며, 단일 트랜잭션입니다. 이들은 서명 counterpart와 동일한 매개변수를 허용합니다.

### `incentiveRewards`

서명자에 대한 Merkl 보상 토큰을 가져오고 청구합니다. 이 메서드에는 서명자가 필요하지만 `earn` 볼트 구성은 필요하지 않습니다.

```ts
const { rewards } = await stable.earn.incentiveRewards.fetch();
const { txHash, tokenCount } = await stable.earn.incentiveRewards.claim();
```

```text
{ txHash: "0xabcd...7890", tokenCount: 1 }
```

`fetch()`는 `MerklRewardsResult` (`{ chainId, rewards: MerklReward[] }`)를 반환하며, 토큰당 순 청구 가능 금액을 포함합니다. `claim()`은 현재 Merkl Merkle 트리에 커밋된 모든 보상을 청구하고 `MerklClaimResult` (`{ txHash, tokenCount }`)를 반환합니다.

:::note
Merkl은 약 2시간마다 Merkle 트리에 보상을 커밋합니다. 아직 업데이트가 보류 중인 보상은 청구할 수 없습니다. 청구할 보상이 없을 때 `claim()`을 호출하면 `StableValidationError`가 발생합니다.
:::

## `createStableReader(config)`

볼트 수익률 및 포지션 데이터를 위한 읽기 전용 `StableReader`를 구성합니다. 서명자는 필요하지 않고, 읽고자 하는 주소만 필요합니다.

```ts
import { createStableReader, Network } from "@stablechain/sdk";

const reader = createStableReader({
  network: Network.Mainnet,
  address: "0xUserAddress",
  earn: { vault: "0xb7Df8db22A5DBBFA9ebeb94b3910aec6a4f05c08" },
});
```

```text
StableReader { earn: { getYield, position, preview, withdrawability, incentiveRewards } }
```

### `StableReaderConfig`

| **필드** | **유형** | **기본값** | **설명** |
| :--- | :--- | :--- | :--- |
| `address` | `string` | | 포지션 및 보상을 읽을 사용자 주소. 필수. |
| `earn` | `{ vault: string }` | | 읽을 볼트. 필수: 누락 시 `createStableReader`는 `StableValidationError`를 발생시킵니다. |
| `network` | `Network?` | `Network.Mainnet` | 대상 네트워크. |
| `rpc` | `string?` | 공개 RPC | RPC 재정의. |
| `merklApiBase` | `string?` | `https://api.merkl.xyz` | Merkl 보상 API 기본 URL. |

## `StableReader`

### `getYield()`

볼트의 현재 순 APY 및 수수료 분석을 반환합니다.

```ts
const vaultYield = await reader.earn.getYield();
```

```text
{ apy: 0.058, native: 0.041, rewards: [ { symbol: "MORPHO", address: "0x...", apr: 0.017 } ], performanceFee: 0.1, managementFee: 0 }
```

`VaultYield`를 반환합니다. `apy`는 보상 부스트를 포함한 수수료 후 총 순 APY이며, `native`는 보상을 제외한 기본 시장 수익률입니다. 모든 값은 소수점 형식입니다(`0.05` = 5%).

### `position()`

구성된 주소의 현재 볼트 포지션을 반환합니다.

```ts
const position = await reader.earn.position();
```

```text
{ shares: 100000000n, sharesFormatted: 100, shareDecimals: 6, assets: 101.2, tokenDecimals: 6, assetAddress: "0x..." }
```

원시 `shares` 잔액, `sharesFormatted` 사람 값, 기본 단위의 `assets` 값과 함께 `VaultPosition`을 반환합니다.

### `preview(params)`

볼트의 실시간 순 APY를 사용하여 특정 금액의 수익률을 기간별로 예측합니다.

```ts
const preview = await reader.earn.preview({ amount: 1000, horizonDays: 30 });
```

```text
{ projectedYield: 4.64, apy: 0.058, horizonDays: 30 }
```

| **매개변수** | **유형** | **설명** |
| :--- | :--- | :--- |
| `amount` | `number` | 예측할 원금, 사람이 읽을 수 있는 형식. |
| `horizonDays` | `number` | 예측 기간(일). |

`YieldPreview` (`{ projectedYield, apy, horizonDays }`)를 반환합니다.

### `withdrawability(params)`

볼트의 유휴 유동성에서 특정 금액을 즉시 인출할 수 있는지 확인합니다.

```ts
const status = await reader.earn.withdrawability({ amount: 5000 });
```

```text
{ isInstant: true, availableLiquidity: 12500.5, tokenDecimals: 6 }
```

| **매개변수** | **유형** | **기본값** | **설명** |
| :--- | :--- | :--- | :--- |
| `amount` | `number` | | 테스트할 금액, 사람이 읽을 수 있는 형식. |
| `tokenDecimals` | `number?` | 온체인 | 기본 자산 소수 자릿수. |

`WithdrawStatus` (`{ isInstant, availableLiquidity, tokenDecimals }`)를 반환합니다. `isInstant`가 `false`인 경우, 인출에는 어댑터 할당 해제가 필요하며, 이는 `stable.earn.withdraw`가 자동으로 처리합니다.

### `incentiveRewards.fetch()`

구성된 주소에 대한 보류 중인 Merkl 보상을 읽습니다. `stable.earn.incentiveRewards.fetch`의 읽기 전용 대응 메서드입니다.

```ts
const { rewards } = await reader.earn.incentiveRewards.fetch();
```

```text
{ chainId: 988, rewards: [ { token: { symbol: "MORPHO", ... }, amount: 1.25, rawAmount: "1250000...", proofs: [...] } ] }
```

`MerklRewardsResult`를 반환합니다.

## `CHAIN_CONFIGS`

`Chain` 열거형으로 키가 지정된 `Partial<Record<Chain, ChainConfig>>`입니다. 각 항목은 `id`, `rpc`, `usdt`, `decimals`를 노출합니다. 지원되는 체인에서 캐노니컬 USDT 주소가 필요하지만 하드코딩하고 싶지 않을 때 사용하십시오.

import { CHAIN_CONFIGS, Chain } from "@stablechain/sdk";

```

```

## `BRIDGE_CHAIN_CONFIGS`

`Partial<Record<Chain, BridgeChainConfig>>`. USDT0 경로에 필요한 LayerZero 필드를 사용하여 `ChainConfig`를 확장합니다. 1.0.4에서 추가되었습니다. `route: "usdt0"`로 `bridge`를 호출하기 전에 체인이 USDT0 경로를 통해 전송할 수 있는지 확인하는 데 사용하십시오.

| **필드** | **유형** | **설명** |
| :--- | :--- | :--- |
| `lzEid` | `number` | 체인의 LayerZero V2 엔드포인트 ID. |
| `oftAdapter` | `Address?` | OFT 어댑터 주소. 어댑터가 배포되지 않은 체인에는 없음. |
| `lzOutbound` | `boolean?` | 어댑터가 존재하지만 아웃바운드 전송 경로가 구성되지 않은 경우 `false`. 없는 경우 아웃바운드가 작동함을 의미. |

```ts
import { BRIDGE_CHAIN_CONFIGS, Chain } from "@stablechain/sdk";

const src = BRIDGE_CHAIN_CONFIGS[Chain.Arbitrum];
console.log(Boolean(src?.oftAdapter) && src?.lzOutbound !== false);
```

```text
true
```

## 오류

모든 SDK 오류는 viem의 `BaseError`를 확장하는 `StableError`를 확장합니다. 오류는 구조화된 메타데이터를 포함하므로 `error.name` 또는 `instanceof`에 따라 분기할 수 있습니다.

| **클래스** | **발생 시점** | **유용한 필드** |
| :--- | :--- | :--- |
| `StableValidationError` | 매개변수 유효성 검사 실패(잘못된 주소, 유한하지 않은 금액, 지원되지 않는 체인, 어댑터 또는 비 USDT0 토큰이 없는 쌍에 대한 `route: "usdt0"`). | `field`, `value` |
| `StableQuoteError` | 견적 요청 실패. `provider`는 `"lifi"`, `"layerzero"`, 또는 `"uniswap"`입니다. | `provider`, `httpStatus`, `providerCode`, `body` |
| `StableTransactionError` | 온체인 단계 실패: 체인 전환, 승인, 전송 또는 되돌리기. | `phase`, `txHash`, `chainId`, `revertReason` |
| `StableNetworkError` | 기본 HTTP/RPC 호출 실패(예: Morpho 또는 Merkl API). | `url` |
| `StableBulkError` | `stopOnError: true`로 실행된 `bulkDeposit` 또는 `bulkWithdraw`가 첫 번째 실패에 도달. | `results`, `succeeded`, `failed` |

```ts
import { StableTransactionError } from "@stablechain/sdk";

try {
  await stable.transfer({ from, to, amount: 1 });
} catch (err) {
  if (err instanceof StableTransactionError && err.phase === "switch_chain") {
    // 사용자가 체인 전환을 거부했습니다.
  }
  throw err;
}
```
