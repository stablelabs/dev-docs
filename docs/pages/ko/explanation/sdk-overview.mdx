# Stable SDK

`@stablechain/sdk`는 Stable의 공식 TypeScript 클라이언트입니다. 가장 많이 사용하는 작업(USDT0 전송, 체인 간 브리지 연결, 토큰 스왑, Stable에서 수익 창출)을 위한 작고, 타입이 지정된 API로 viem을 래핑합니다. 라우팅, 승인, 소수점 이하 자릿수 및 체인 전환은 자동으로 처리됩니다.

```ts
import { createStable, Network } from "@stablechain/sdk";
import { privateKeyToAccount } from "viem/accounts";

const stable = createStable({
  network: Network.Mainnet,
  account: privateKeyToAccount("0x..."),
});

const { txHash } = await stable.transfer({
  from: "0xYourAddress",
  to: "0xRecipient",
  amount: 10,
});
```

```text
txHash: 0x8f3a...2d41
```

## SDK의 기능

- **`transfer`**: Stable에서 기본 USDT0 또는 모든 ERC-20을 전송합니다. 가스비는 USDT0로 자동으로 지불됩니다.
- **`quoteBridge` / `bridge`**: 기본 USDT0 브리지 또는 LI.FI 애그리게이터를 통한 크로스체인 전송. 라우트는 자동으로 선택되거나 강제로 하나를 지정할 수 있습니다. 승인 및 체인 전환은 내부적으로 처리됩니다.
- **`quoteSwap` / `swap`**: 슬리피지 보호 및 ERC-20 승인이 내부적으로 처리되는 Stable의 표준 Uniswap v3 배포에서 동일 체인 토큰 스왑. 애그리게이터 수수료 없음.
- **`earn`**: Morpho V2 볼트에 USDT0를 공급하여 수익을 얻고, 인출 또는 상환하고, Merkl 인센티브 보상을 청구합니다. 승인 및 어댑터 할당 해제가 자동으로 처리됩니다.
- **`createStableReader`**: 볼트 APY, 포지션, 수익 예측 및 즉시 인출 가능성 확인을 위한 읽기 전용 클라이언트. 서명자 필요 없음.

SDK는 npm에 [`@stablechain/sdk`](https://www.npmjs.com/package/@stablechain/sdk)로 게시되어 있으며, 피어 종속성으로 `viem >= 2.0.0`을 필요로 합니다.

## 두 가지 브리지 경로

:::note
네이티브 USDT0 경로는 버전 1.0.4에서 추가되었습니다. 이전에는 모든 브리지가 LI.FI를 통해 이루어졌습니다.
:::

`bridge`는 네이티브 USDT0 경로와 직접 통신합니다. 소스 체인에서 LayerZero의 OFT 어댑터를 호출하여 USDT0를 소각하고 대상 체인에 발행하므로 프로토콜 수수료 없이 1:1로 전체 금액을 받습니다. 소스 가스비와 LayerZero 메시징 수수료를 지불하고 DVN 확인을 기다려야 합니다. LI.FI 경로는 대안입니다. 모든 토큰 쌍을 처리하고 더 빠르게 정산되지만, 애그리게이터가 수수료를 받습니다.

기본적으로 SDK가 자동으로 경로를 선택합니다. 양쪽 체인에 OFT 어댑터가 있고 각 체인의 토큰이 USDT0인 경우 USDT0 경로를 사용하고, 그렇지 않으면 LI.FI로 폴백합니다. `route`를 설정하여 재정의할 수 있습니다.

```ts
import { Chain } from "@stablechain/sdk";

const { txHash } = await stable.bridge({
  fromChain: Chain.Ethereum,
  toChain: Chain.Stable,
  fromToken: "0x6C96dE32CEa08842dcc4058c14d3aaAD7Fa41dee", // 이더리움의 USDT0
  toToken: "0x779Ded0c9e1022225f8E0630b35a9b54bE713736", // Stable의 USDT0
  amount: 100,
  route: "usdt0",
});
```

```text
{ txHash: "0xabcd...7890", toAmount: 100 }
```

쌍에 어댑터가 없는 경우 수수료를 부과하는 경로로 조용히 폴백하는 대신 `"usdt0"`를 강제하면 `StableValidationError`가 발생합니다. 속도가 필요하거나 USDT0 이외의 토큰이 필요한 경우 `"lifi"`를 강제하는 것이 비상 탈출구입니다. 체인별 지원 테이블 및 인용문이 반환하는 수수료 필드에 대해서는 [SDK 참조](/ko/reference/sdk#bridgeroute)를 참조하십시오.

:::note
`Chain.Base` 및 `Chain.BSC`에는 USDT0 OFT 어댑터가 없으므로 항상 LI.FI를 통해 라우팅됩니다. USDT0 경로는 LI.FI가 메인넷 체인만 지원하므로 테스트넷에서 작동하는 유일한 경로이기도 합니다.
:::

## 언제 사용하고 언제 사용하지 않아야 하는가

라우팅 및 승인 상용구를 숨기는 타입이 지정된, 독단적인 클라이언트를 원할 때 SDK를 사용하십시오. 트랜잭션 구성, 사용자 지정 가스 전략 또는 전송/브리지/스왑 외부의 계약 호출을 직접 제어해야 할 때는 원시 viem 또는 ethers로 내려가십시오.

:::note
SDK는 모든 viem 호환 서명자로 서명합니다. 프라이빗 키 `Account`, `custom(window.ethereum)`과 같은 브라우저 `Transport`, 또는 미리 빌드된 `WalletClient`(예: wagmi의 `useWalletClient`에서 반환된 클라이언트) 등이 있습니다.
:::
